# Avatar

Coloque sua foto nesta pasta com o nome:

`avatar.jpg`

A foto é convertida para ASCII automaticamente pelo `generate.py`.

Para obter um resultado melhor:
- rosto de frente ou levemente de frente;
- boa iluminação;
- fundo relativamente simples;
- rosto e ombros ocupando boa parte da imagem;
- imagem nítida;
- evite óculos escuros ou objetos cobrindo o rosto.

Você pode usar uma foto comum; não precisa ser uma foto profissional.
